What it checks

Every check your delivery needs

Grouped by the job in front of you, from a quick structure check to a full QC pass. Plain reports you can hand to a client or an operator.

Package integrity

📄

Structure and references

Checks that ASSETMAP, PKL and CPL line up and that every asset they point to is actually present. Catches duplicate asset IDs across packages.

✅

Hashes and file sizes

Verifies the SHA-1 hash and size of every file, so a corrupt or half-copied asset gets caught before it reaches a theater or a facility.

🔒

Signatures and certificates

Validates the XML signatures and the certificate chain, flags expired certs and malformed package XML, and catches an encrypted package that was left unsigned.

Picture, color and HDR

📐

Resolution and format

Confirms the 2K or 4K container, Flat / Scope / Full and aspect ratio, and flags non-standard sizes.

🎬

Bitrate limits

Per-frame picture bitrate with min, max and average, checked against the DCI limits (250 Mbps at 2K, 500 at 4K).

🌈

Color space

Detects XYZ / DCI-P3 / Rec.709 and confirms 12-bit depth, with out-of-gamut sampling.

🌞

HDR metadata

HDR10, HLG and Dolby Vision metadata, with MaxCLL and MaxFALL checks.

🎥

Stereoscopic 3D

Left- and right-eye frame counts matched, for 3D packages.

Sound and loudness

🔊

Levels

Per-channel peak and RMS in dBFS, with warnings on clipping near 0 dBFS and silent channels.

🎙

Loudness

EBU R128 / ATSC A/85 loudness measurement, and normalization to a target such as -23 LUFS when you need it.

🎵

Channels and labels

Checks the channel layout (2.0, 5.1, 7.1, immersive) and MCA labels against the actual sound file.

🌐

Dolby Atmos

Detects immersive audio (IAB) essence with an estimated object count.

🔗

A/V sync

Flags picture and sound drift, per reel.

Subtitles and accessibility

📜

Timing

Subtitle timing rules: in/out order, overlaps, minimum event duration, gap spacing, and a too-early first subtitle.

📄

Readability

Line count and length limits, plus closed-caption character-set checks and required elements like language and font.

♿

Accessibility tracks

Detects and checks audio description, hearing-impaired and closed-caption tracks.

Encryption and keys

🔒

Encryption status

Spots encrypted assets and mixed-encryption packages, and tells you when a KDM will be required.

🔑

KDM checks

Validates KDMs: the validity window (expired or not-yet-valid) and that the key matches the right CPL in the package.

Automated QC

🔍

Automatic QC scan

Finds black frames, freeze frames, audio silence and clipping automatically, with thresholds you can set.

📋

QC reports

Clean HTML or PDF reports with package, track and per-track loudness summaries, ready for a client name and title.

📈

Compare two packages

Diff two DCPs to see exactly what changed, down to a perceptual picture fingerprint.

Delivery targets

🎥

Theater server profiles

Check a package against pre-built profiles for Dolby, Barco, Christie, GDC and IMAX servers before it goes on-screen.

🏭

Facility ingest check

A pre-delivery readiness pass for theater ingest, so a package clears the door on the first try.

🆔

Streamer IMF delivery

Netflix IMF delivery checks, with deep IMF conformance run through Netflix Photon for IMF packages.

🗝

ISDCF naming

Validates the content title against the ISDCF naming convention: content type, resolution, audio and language.

Fix and automate

🔧

Auto-fix common problems

Repairs the usual suspects: hash mismatches, wrong SMPTE/Interop namespaces and invalid ContentKind, with a dry-run to preview first.

📁

Watch folders

Point it at an ingest folder and it checks new packages as they land.

Automation

Fit it into your pipeline

The command-line build does everything the app does, so you can batch a whole day of deliveries, watch an ingest folder, or wire checks into your own tools.

Command line

Check a package

Run a full check and get a pass/fail exit code you can act on.

dcpdoctor /path/to/DCP
Watch folder

Auto-check on arrival

Watch an ingest folder and check each new package as it lands.

dcpdoctor watch /ingest/incoming
REST API

Call it from your tools

Run a small HTTP service and POST a package path to check it.

dcpdoctor serve --port 8080
For developers

Build from source

The project is open source under GPL. The core and command line are written in Rust; the desktop app wraps them with Tauri.

# command line (needs a Rust toolchain)
git clone https://github.com/PostPerfection/dcpdoctor.git
cd dcpdoctor/rust && cargo build --release

# desktop app (needs Node.js + pnpm as well)
cd ../gui && pnpm install
pnpm tauri build

Full build notes and platform prerequisites are in the README. Source, issues and pull requests live on GitHub.
